### 2a. Root cause, located in the code

`code/cpk.py:486-497`:

```python
def oracle(gates, tag="", depth=None):
    """The repo's independent oracle, in a FRESH subprocess."""
    fd, path = tempfile.mkstemp(suffix='.json')
    with os.fdopen(fd, 'w') as f:
        json.dump({"gateCount": len(gates), "gates": gates}, f)
    cmd = [sys.executable, os.path.join(ROOT, 'verify_circuit.py'), path]
    ...
    return ok, r.stdout.strip(), path
```

The circuit is written to a **`tempfile.mkstemp` path**, handed to
`verify_circuit.py`, and the caller keeps only the verdict string. `grep` over
`code/*.py` finds **no writer into `found/` at all**. The artifact was never
persisted; it went with `/tmp`.
