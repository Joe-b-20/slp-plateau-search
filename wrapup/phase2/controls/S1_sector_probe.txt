-- 1. the column polynomials in R = GF(2^8)[y]/(y^4+1) ------------------
   c_fwd      = 02*y^0 + 03*y^1 + 01*y^2 + 01*y^3
   c_inv      = 0e*y^0 + 0b*y^1 + 0d*y^2 + 09*y^3
   substitute y = 1 + v   (v = y+1, v^4 = 0 in this ring):
   c_fwd      = 01*v^0 + 02*v^1 + 01*v^3
   c_inv      = 01*v^0 + 02*v^1 + 04*v^2 + 09*v^3

   GF(2)-scalar structure -- which powers of x (=the byte 0x02) appear
   on each v-power.  theory.py's (p,q) split assumes EXACTLY x^0 and x^1:
     c_fwd : {0: [0], 1: [1], 2: [], 3: [0]}
     c_inv : {0: [0], 1: [1], 2: [2], 3: [0, 3]}
     x-powers used:  forward [0, 1]   inverse [0, 1, 2, 3]
   => forward needs the dual chain to depth 1 (p-part + ONE tap 2*d_k)
   => inverse needs it to depth 3 (p-part + taps 2,4,8 * d_k): the (p,q) pair coordinate is NOT enough

-- 1b. where W = 0x7 and SECTOR_TARGETS actually come from ---------------
   measured (p,q) per output column, over all eight sectors.
   NOTE the index map: SECTOR_TARGETS is indexed by the RING EXPONENT
   a, output byte col = (4-a) mod 4 (theory.YBYTE; trace duality
   reverses byte order).
     column 0 (exponent a=0): (p,q) = (0x9, 0xe)   SECTOR_TARGETS[0] = (0x9, 0xe)   ==
     column 1 (exponent a=3): (p,q) = (0x7, 0xa)   SECTOR_TARGETS[3] = (0x7, 0xa)   ==
     column 2 (exponent a=2): (p,q) = (0xd, 0x6)   SECTOR_TARGETS[2] = (0xd, 0x6)   ==
     column 3 (exponent a=1): (p,q) = (0xb, 0x2)   SECTOR_TARGETS[1] = (0xb, 0x2)   ==
   y = 0x3, y^-1 = 0xf in T = F2[v]/(v^4)
   W := y^-1 * p(column 0) = 0x7   theory.W = 0x7   ==
   cross-check q(column 0) = v * W ?  v*W = 0xe  measured 0xe   ==
   closed form SECTOR_TARGETS[a] = (y^(a+1) W, v y^a W) reproduces all four columns: PASS
   => THE COMPUTATION: measure (p,q) of the targets in the dual-chain
      frame, observe they are column-shifts of one another, solve for
      the unit W.  It is a two-coordinate frame ONLY because c_fwd's
      scalars are {x^0, x^1}.  For the inverse this readout does not
      even parse: see section 3 (0/32 sector-pure) and section 4.

-- 4. re-deriving the sector frame for the inverse -----------------------
   forward sector S_k = span{d_k, 2 d_k} (x) T  (two taps, from the
   scalars {x^0, x^1} of c_fwd).  c_inv uses {x^0..x^3}, so try
   S'_k = span{d_k, 2 d_k, 4 d_k, 8 d_k} (x) T.
   |S'_k| line-support per k: [4, 5, 5, 7, 7, 6, 5, 4]
   inverse targets expressible as p d_k + q 2d_k + r 4d_k + s 8d_k for a single k: 32/32
     column 0 (exponent a=0): 1 distinct (p,q,r,s) across the 8 sectors -> [('0x9', '0xe', '0x4', '0x8')]
     column 1 (exponent a=3): 1 distinct (p,q,r,s) across the 8 sectors -> [('0x7', '0xa', '0xc', '0x8')]
     column 2 (exponent a=2): 1 distinct (p,q,r,s) across the 8 sectors -> [('0xd', '0x6', '0x4', '0x8')]
     column 3 (exponent a=1): 1 distinct (p,q,r,s) across the 8 sectors -> [('0xb', '0x2', '0xc', '0x8')]
   universal quadruple at a=0: ('0x9', '0xe', '0x4', '0x8')   (= (y*W, v*W, v^2, v^3) with W = 0x7)
   column-shift law  SECTOR_TARGETS_inv[a] = y^a * that quadruple: PASS
